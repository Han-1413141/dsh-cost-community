## 数据接入

浏览器直接导入 `/shared/analysis.js` 中的 `analyzeDataset`、`anonymizeAnalysis`，与服务端使用相同校验与计算口径。公共接口按根目录 `api-contract.md`：

- `GET /api/health`：读取试运行到期日，在贡献页与方法页显示。
- `GET /api/community`：真实聚合；零记录显示零，503 显示不可读取，不作零数据推断。
- `POST /api/contributions`：仅接受 `user_reported`，主动确认后发送带同意版本的原始 JSON，服务端校验并保存统计摘要。
- `DELETE /api/contributions/:id`：撤回密钥置于 Authorization Bearer 请求头，不进入 URL。

前端已适配 `quota_source`、`window_type`、`coverage`、`community_eligible`、`payment_category`。本地估算、滚动窗口或不完整覆盖仅作个人观察；贡献预览提示完整周期与归属为用户声明。社区用“不同贡献编号”而非独立真人表示披露门槛。

撤回凭证只存在当前内存，支持 JSON 下载与重新导入，不使用 localStorage、分析 SDK 或第三方追踪。未上传成功前不声称进入社区。输入文案、导入标识与 API 文案均经 HTML 转义后显示。
