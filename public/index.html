01 / QUOTA VALUE

每 1% 额度对应的用量价值

新增 Token ÷ 新增已用额度百分点
新增 API 等价费用 ÷ 新增已用额度百分点

两次读数必须来自同一提供商、套餐、额度池、窗口和目录价格快照。已用额度要严格增加，累计 Token 与等价金额不能回退。窗口重置后，另起一组样本。

API 等价费用按目录价衡量用量价值，与订阅实付分开呈现。若同一账号还有其他客户端消耗额度，本地统计未覆盖其用量，每 1% 换算会被低估。

Token 怎样避免重复计算？

必须显式声明输入是否包含缓存读写、输出是否包含 reasoning。网站按声明计算非重复总量，并检查总数一致；未知计数语义不能生成可比总量。

02 / TASK VALUE

把成本对应到真正验收的任务

周期净实付 ÷ 验收通过的不同任务数
净实付 = 订阅 + 超额 + 其他 API 支出 − 退款

统计完整支付周期内的全部任务。未通过、放弃和重试产生的支出保留在分子里；成功率以全部不同任务为分母，尝试数另列，避免把一次任务的多轮重试当成多个成果。

比较条件至少包括任务类型、难度、验收标准、支付周期长度和月份。模型版本、工具设置与真实工作内容仍可能不同，因此结果用于描述观察，不解释为因果排名。建议在首次尝试前登记验收标准，并连续记录观察期内的全部任务。

多模型共享套餐按 workflow 组合统计，不能把完整月费重复分摊给每个模型。人工时间与失败次数同时查看。赠送、试用或优惠数据应单独分组，不能代表正常续费体验。

不直接平均个人比值

社区数据是用户自报，未逐条独立核验。五份不同贡献编号是记录披露门槛，不代表五个独立真人，也不代表统计显著。未达门槛的组只公开条件和记录数，不发布指标。

额度记录按读数来源、窗口类型与覆盖范围区分。只有固定重置窗口、覆盖完整且非本地估算的记录进入公开额度聚合；其他记录保留为个人观察。常规付费、促销、赠送与试用周期分组统计。

任务成本以总净实付除以总验收任务，额度价值以总 Token 除以总额度百分点。样本量、验收率、人工投入与分组条件跟随结果展示，不用单一分数掩盖取舍。

04 / EXTERNAL CONTEXT

AA 公开数据作为外部参照

方案将 Artificial Analysis（AA）已公开的模型能力、价格与评测成本数据作为外部参照。对照时先对齐模型版本、推理设置和数据日期，再结合本地验收率、每项验收任务成本与人工投入，解释公开评测与真实编码任务之间的差异。

本站当前提供方法说明与官方外链，尚未完成 AA 数据的自动接入。公开模型评测成本与个人订阅实付分别保留来源和口径，不直接合成一个综合性价比分数。

05 / DATA CHOICE

先本地预览，再由你确认分享

工作摘要由你逐项选择功能类别、代码变更区间与难度，不填写具体业务描述、不上传代码。若在本地输入代码行数，浏览器只将其换算为区间，精确行数不进入发送数据。难度沿用所属周期。添加、修改或移除摘要后，发送预览会重新计算，两项确认同时取消；有摘要时须另外勾选已逐项核对。服务器只保存类别与区间的任务数量分布，不保存逐任务摘要。

本地分析不上传文件。贡献预览先检查原任务标识是否重复，再把任务与窗口标识换成临时随机别名；工作流名称用本浏览器的随机密钥生成稳定别名。原任务名、窗口名、工作流名和本地密钥不发送。提供商、套餐、模型、额度池和价格快照仍保留为公开比较字段，请使用适合公开的标识。

只有主动勾选同意并点击提交后，浏览器才发送预览中的去标识逐任务统计记录、验收结果、尝试次数、人工分钟、Token、费用与额度快照。服务器重新校验和计算，只保存周期与额度摘要，不保存逐任务记录、任务标识及原始快照。服务商基础访问日志可能记录网络请求信息，不作为公开数据。

工作流去标识使用随机 256 位 HMAC 密钥，以不可导出的 CryptoKey 保存在当前站点的浏览器 IndexedDB 中；不保存原文件、原名称或映射表。同一浏览器再次导入相同工作流时别名稳定。更换浏览器或清除站点数据会产生新别名；它不代表真人身份验证，也不用于承诺跨用户识别相同组合。

成功后生成贡献编号与撤回密钥。撤回密钥不同于本地工作流密钥：它只返回一次，服务端保存其哈希；浏览器仅在当前页面内存中保留，不保存到 localStorage 或 IndexedDB。撤回后该记录立即停止参与公开聚合。请自行保管凭证。

网站前端、后端与统计方法的代码以 MIT 公开，可检查字段处理、计算、保存和撤回实现。代码许可证不自动授予用户数据的再利用许可。站内仅按已同意的用途公开聚合；下载的去标识周期摘要由用户自行决定是否发布及采用何种许可，网站没有单份摘要公开接口。
