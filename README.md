## 本地启动

```powershell
npm ci
npm start
```

打开 `http://localhost:3000`。没有 `DATABASE_URL` 时，个人计算和演示可使用；`/api/health` 明确返回 `degraded`，真实社区和上传返回 503。生产入口没有 JSON、SQLite 或内存存储回退，不会把暂存在进程内的数据称为已保存。

用于实际保存的环境变量：

| 变量 | 用途 |
|---|---|
| `DATABASE_URL` | PostgreSQL 连接。Render 使用同区域数据库的内部 URL，配置到环境变量，不提交代码库。 |
| `APP_ORIGIN` | 规范站点 Origin，如 `https://example.onrender.com`；未设置时采用 Render 的 `RENDER_EXTERNAL_URL` 或本机 Origin。 |
| `ANONYMIZATION_SECRET` | 至少 32 个随机字节对应的机密字符串，用于再次转换客户端已去标识的工作流别名；不可放前端或日志。缺失时工作流上传返回 503。 |
| `TRIAL_STORAGE_EXPIRES_AT` | 免费数据库实际到期 UTC 时间。当前部署值为 `2026-11-08T09:11:08Z`，即北京时间 2026 年 11 月 8 日 17:11:08。 |
| `PORT` | Web 监听端口；默认 3000，Render 自动提供。 |

数据库连接按 `pg` 对连接 URL 的配置执行。数据库创建好后，首次健康检查或请求会在事务中建立表。需要的表是 `contributions`、`quota_samples`、`cost_periods`。应用最多使用 5 个数据库连接。

## 数据与统计口径

精确接口、枚举和错误格式见 `api-contract.md`；结构见 `shared/schema.json`。浏览器先用 `/shared/analysis.js` 的 `analyzeDataset` 校验原始任务标识和计算。贡献预览与可分享导出调用 `/shared/privacy.js` 的 `prepareContribution` 替换任务、窗口和工作流标识；只有用户核对实际发送内容并主动同意后，才发送去标识的逐任务统计记录。

每份贡献最多 256 KiB、20 个额度样本、12 个成本周期和总计 1000 个任务。不接收原文件、文件名、提示词、代码、账号或任意说明文字。允许的产品标识是受限字符字符串，但格式检查不能证明其绝不含个人信息；贡献人仍须使用公开产品或匿名标识。

Token 必须明确 input 是否包含缓存、output 是否包含 reasoning，并校验 `normalized_total_tokens`。额度差分要求同一窗口内顺序采样、百分点严格增加、各累计组件不回退。滚动窗口、本地估算或覆盖不全的额度只作个人计算，不入社区统计。

成本只比较覆盖全部尝试任务的完整周期。一个周期对应相同任务类型、难度和验收标准，混用模型则标为 `workflow`，不归到最后使用的模型。净实付为订阅、超额、其他 API 实付合计减已确认退款。赠送额度、试用、促销、常规付费与未知付款类别分组展示。页面显式列出不同任务总数、已验收任务、未验收任务、验收率、全部尝试和重试数。不同任务按每个完整周期内的 `task_id` 去重，再按周期合计；重试不增加不同任务数，不宣称跨周期项目去重。验收率分母保留失败任务；`failed_attempts` 指未通过验收的尝试，不代表模型故障率。

社区按 `Σ净实付 / Σ已验收任务` 和 `ΣToken / Σ百分点` 聚合。至少 5 个不同贡献编号才发布一组指标；低于门槛的组返回 `metrics:null`。贡献编号不是独立真人身份，门槛也不是统计显著性。全部数据仍标为用户自报、未独立核验，不产生综合分数或真实厂商优胜结论。

## 保存、去重与撤回

浏览器先校验，再将任务和窗口标识替换为临时随机别名；工作流标识由仅在当前站点浏览器 IndexedDB 保存的非导出 256 位 HMAC CryptoKey 生成。该存储只有随机密钥，不存文件、原名称或映射表，原标识与本地密钥不上传。同一浏览器重复导入保持工作流别名稳定；清除站点数据或换浏览器后会改变，不承诺跨用户识别同一组合。

上传的是去标识的逐任务统计记录及额度快照，服务端校验并重新计算后只保存周期与额度摘要，不保存逐任务记录、任务别名及原始快照。服务端再次 HMAC 转换工作流别名后才保存和返回。提供商、套餐、模型、额度池与价格快照等公开比较字段保留，用户须确认适合公开。贡献摘要下载直接使用服务端返回的实际保存结果。

整份数据和每条样本分别做规范化指纹去重；对象键顺序、数组顺序、task_id/window_id 随机改名不改变指纹。工作流本地稳定别名仍参与指纹，保持有效不同组合的区分。指纹不提供真人去重，也不能阻止所有有意伪造。单份文件的重叠额度观察区间及重叠支付周期会被拒绝。

创建贡献返回随机撤回密钥及下载凭证，服务器只保存 SHA-256 哈希。用户用 `Authorization: Bearer <withdrawal_key>` 撤回；服务端在事务中核对密钥并级联删除摘要，后续聚合立即排除。公开接口不提供原始贡献记录或密钥查询。撤回凭证只留在当前页面内存中供用户下载，不放 URL、localStorage、IndexedDB 或应用日志；它与本地工作流去标识密钥分开。密钥丢失不能只凭公开编号撤回。

限流、同源 Origin 校验、256 KiB 正文限制、参数化 SQL、数据库唯一约束和事务均在服务端执行。日志只写启动信息，不输出请求正文、认证头、数据库 URI 或异常原文。

## Render 的实际边界

本轮使用免费 Web + 免费 Postgres，定位为 30 日试运行。页面显示“试运行，当前数据存储至2026年11月8日，支持下载与撤回”。数据库到期后不能继续宣称保存服务可用，也不承诺 90 天留存。

Render 免费 Web 空闲后会休眠，本地文件系统在重启、重新部署和休眠时丢失。数据必须保存在 Postgres。免费 Postgres 为 1 GB，创建后 30 天到期，且没有备份；应用的撤回删除作用于活动数据库。长期运行应先安排持久数据库方案，再更新对应的留存说明。[官方免费层说明](https://render.com/docs/free)

使用同区域内部 URL，数据库公网 IP 允许列表保持空。`render.yaml` 是新建部署模板；主代理已经创建的数据库应由主代理按实际资源绑定，不能再次应用模板创建重复资源，不能改动其他项目的免费服务。
