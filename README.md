# 编码成本透明化与性价比普惠 · 网站 MVP

该网站基于 DeepSeek Harness（DSH）用量统计工作的数据方法扩展，提供独立的套餐额度差分、完整周期成本分析、结构数据贡献、公开摘要与撤回功能。前端为同源 HTML/CSS/JS，后端为 Node.js + Express + PostgreSQL，输入由 Ajv 和前后端共用的计算模块双重校验。

**真实社区初始为 0。**构造数据只用于前端演示与独立测试；贡献接口拒绝 `synthetic`。后台不抓取 AA 或其他第三方榜单，目录等价金额由用户按自己标明的价格快照提供，不能称作本站已核验的官方价格。

本项目以 MIT 许可证发布，见 `LICENSE`；沿用 `Copyright (c) 2026 dsh-cost-meter contributors`。来源项目为 [Han-1413141/dsh-cost-meter](https://github.com/Han-1413141/dsh-cost-meter)，网站在本轮离线分析原型的计算与输入合同上继续开发。DeepSeek、DeepSeek Harness 和 Artificial Analysis 名称用于说明兼容关系或来源，不表示这些机构发布或核验了社区数据。

## 本地启动

```powershell
npm ci
npm start
```

打开 `http://localhost:3000`。没有 `DATABASE_URL` 时，个人计算和演示可使用；`/api/health` 明确返回 `degraded`，真实社区和上传返回 503。生产入口没有 JSON、SQLite 或内存存储回退，不会把暂存在进程内的数据称为已保存。

用于实际保存的环境变量：

| 变量 | 用途 |
|---|---|
| `DATABASE_URL` | PostgreSQL 连接。Render 使用同区域数据库的内部 URL，配置到环境变量，不提交代码库。 |
| `APP_ORIGIN` | 规范站点 Origin，如 `https://example.onrender.com`；未设置时采用 Render 的 `RENDER_EXTERNAL_URL` 或本机 Origin。 |
| `ANONYMIZATION_SECRET` | 至少 32 个随机字节对应的机密字符串，用于稳定地匿名化工作流名称；不可放前端或日志。缺失时工作流上传返回 503。 |
| `TRIAL_STORAGE_EXPIRES_AT` | 免费数据库实际到期 UTC 时间。当前部署计划值为 `2026-11-08T09:11:00Z`，即北京时间 2026 年 11 月 8 日 17:11。 |
| `PORT` | Web 监听端口；默认 3000，Render 自动提供。 |

数据库连接按 `pg` 对连接 URL 的配置执行。数据库创建好后，首次健康检查或请求会在事务中建立表。需要的表是 `contributions`、`quota_samples`、`cost_periods`。应用最多使用 5 个数据库连接。

## 数据与统计口径

精确接口、枚举和错误格式见 `api-contract.md`；结构见 `shared/schema.json`。浏览器可直接导入 `/shared/analysis.js` 的 `analyzeDataset` 和 `anonymizeAnalysis`，先在本地查看结果，只有用户另行同意上传才发送白名单结构。

每份贡献最多 256 KiB、20 个额度样本、12 个成本周期和总计 1000 个任务。不接收原文件、文件名、提示词、代码、账号或任意说明文字。允许的产品标识是受限字符字符串，但格式检查不能证明其绝不含个人信息；贡献人仍须使用公开产品或匿名标识。

Token 必须明确 input 是否包含缓存、output 是否包含 reasoning，并校验 `normalized_total_tokens`。额度差分要求同一窗口内顺序采样、百分点严格增加、各累计组件不回退。滚动窗口、本地估算或覆盖不全的额度只作个人计算，不入社区统计。

成本只比较覆盖全部尝试任务的完整周期。一个周期对应相同任务类型、难度和验收标准，混用模型则标为 `workflow`，不归到最后使用的模型。净实付为订阅、超额、其他 API 实付合计减已确认退款。赠送额度、试用、促销、常规付费与未知付款类别分组展示。验收率分母保留失败任务；`failed_attempts` 指未通过验收的尝试，不代表模型故障率。

社区按 `Σ净实付 / Σ已验收任务` 和 `ΣToken / Σ百分点` 聚合。至少 5 个不同贡献编号才发布一组指标；低于门槛的组返回 `metrics:null`。贡献编号不是独立真人身份，门槛也不是统计显著性。全部数据仍标为用户自报、未独立核验，不产生综合分数或真实厂商优胜结论。

## 保存、去重与撤回

服务端不保存逐任务明细和原始额度快照，只保存计算后的白名单摘要。产品和公开分组字段保留；自定义工作流名称经过服务端 HMAC 变成匿名标识后才保存和返回。HMAC 仅表示同一声明组合，不核验组合定义真实性。

整份数据和每条样本分别做规范化指纹去重；对象键顺序、数组顺序、task_id/window_id 改名不能绕过。指纹不提供真人去重，也不能阻止所有有意伪造。单份文件的重叠额度观察区间及重叠支付周期会被拒绝。

创建贡献返回随机撤回密钥及下载凭证，服务器只保存 SHA-256 哈希。用户用 `Authorization: Bearer <withdrawal_key>` 撤回；服务端在事务中核对密钥并级联删除摘要，后续聚合立即排除。公开接口不提供原始贡献记录或密钥查询。凭证不放 URL、浏览器 localStorage 或应用日志。密钥丢失不能只凭公开编号撤回。

限流、同源 Origin 校验、256 KiB 正文限制、参数化 SQL、数据库唯一约束和事务均在服务端执行。日志只写启动信息，不输出请求正文、认证头、数据库 URI 或异常原文。

## Render 的实际边界

本轮使用免费 Web + 免费 Postgres，定位为 30 日试运行。页面显示“试运行，当前数据存储至2026年11月8日，支持下载与撤回”。数据库到期后不能继续宣称保存服务可用，也不承诺 90 天留存。

Render 免费 Web 空闲后会休眠，本地文件系统在重启、重新部署和休眠时丢失。数据必须保存在 Postgres。免费 Postgres 为 1 GB，创建后 30 天到期，且没有备份；应用的撤回删除作用于活动数据库。长期运行应先安排持久数据库方案，再更新对应的留存说明。[官方免费层说明](https://render.com/docs/free)

使用同区域内部 URL，数据库公网 IP 允许列表保持空。`render.yaml` 是新建部署模板；主代理已经创建的数据库应由主代理按实际资源绑定，不能再次应用模板创建重复资源，不能改动其他项目的免费服务。

## 必要检查

```powershell
npm test
```

默认测试使用 `tests/memory-store.js`，该文件只用于测试，生产启动入口不会引用它。覆盖主要计算、Token 语义、拒绝规则、同源和授权、上传去重、5 份贡献门槛、匿名化、限流、密钥撤回与无数据库 503。它不证明 PostgreSQL 已在云端实测。

一次性的本地浏览器集成可以运行 `node tests/dev-server.js`，打开 `http://127.0.0.1:4317`。它只监听本机、以空内存库启动，忽略 `DATABASE_URL`，退出即丢失测试数据，不能部署为生产服务。可通过 `TEST_PORT` 修改测试端口。

真实数据库集中检查另用 `tests/postgres.test.js`：只有显式配置 `TEST_DATABASE_URL` 才运行，绝不自动使用 `DATABASE_URL`。测试通过相同 `PgStore` 在 `test_<随机十六进制>` 独立 schema 内验证唯一约束、事务回滚、新连接读取、汇总和级联撤回，最后删除这个测试 schema。不能修改脚本使其在公开统计表中写构造数据。

```powershell
# 在受控环境注入 TEST_DATABASE_URL，不把连接字符串放入聊天或日志。
npm run test:integration
```

部署是否成功、数据库是否连接、真实数据库测试是否执行，应分别根据实际结果报告。README 的能力说明不等于线上已经完成验证。
